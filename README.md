# PageFuse

Bilingual product, support and privacy pages for [PageFuse](https://apps.apple.com/app/id6816576688).

- `index.html` — English and Simplified Chinese product page. The language switch also changes real app screenshots.
- `privacy.html` — bilingual privacy policy.
- `assets/` — optimized screenshots captured from the PageFuse app and its icon.

The site is static and can be served from the repository root with GitHub Pages. No build step is needed.
